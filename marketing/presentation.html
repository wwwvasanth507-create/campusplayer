Feature 1
📹 Video Management
Professional HLS video streaming built right into the platform
⚡ HLS Streaming
FFmpeg converts uploaded videos to HLS format (.m3u8) for adaptive, buffer-free streaming across all devices.
🖼️ Auto Thumbnails
Thumbnails are auto-generated from the video's first frame using FFmpeg during processing.
📂 Playlists
Teachers organize videos into playlists. Students see only playlists from their enrolled classes.
💬 Comments & Replies
Threaded comment section under each video for student-teacher discussion.
🔒 Admin Locks
Admin can lock video speed controls and prevent skipping to enforce full viewing.
📊 Analytics
Track every view: who watched, start/end time, completion percentage per student.
Feature 2
📋 Attendance System
Smart, time-locked attendance with automatic parent notifications
🟢
Present
On-time arrival tracked
⏰
Late
Auto-detected by time window
❌
Absent
SMS sent to parent automatically
🔒 Time-Locked Window
Admin sets lock time (e.g., 09:10 AM). Attendance only marks during open window — prevents backdating.
📄 PDF Reports
Generate detailed attendance PDFs per student or class — with date-wise breakdown and statistics.
Feature 3
📝 Quiz System
Create, assign, and grade assessments with automated XP rewards
  • Teacher creates MCQ quizzes with 4 options
  • Assign quiz to a specific class or global
  • Students take quiz and submit answers
  • Automatic scoring & XP award on completion
  • Teacher views quiz result reports
  • Delete question or entire quiz anytime
Quiz Flow
Create Quiz → Add Questions → Assign Class → Students Take → Auto Grade → View Reports
📊 Quiz Reports
See per-student scores, average marks, pass rate, and question-wise results.
🎮 XP on Completion
Students earn +25 XP per quiz completed — motivating participation.
🗑️ Easy Management
Delete individual questions or entire quizzes from the quiz management page.

Feature 7
📲 SMS Parent Alerts
Automated parent notifications using Selenium-powered SMS automation
  • Selenium automates Google Messages (web.messages.google.com)
  • Sends personalized SMS to each parent's phone
  • Absent student alerts with custom message
  • Class-wide bulk SMS option
  • Lock mechanism prevents duplicate sends
  • Configurable admin phone number
