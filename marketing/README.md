Simply **double-click** either HTML file to open it in your browser.

## 📽️ advertisement.html — The Ad

**Purpose:** A stunning animated advertisement for screen recording or live demos.

**Features:**
- ✅ 8 animated slides with auto-play (5 seconds each)
- ✅ Particle star background
- ✅ Keyboard navigation (← → Arrow keys or Space)
- ✅ Clickable dot navigation
- ✅ "Skip to End" button
- ✅ Fully responsive

**Slides covered:**
1. 🎓 Hero / Brand Introduction
2. 📊 Key Stats & Numbers
3. 👥 Three User Roles
4. 📹 Video Management Features
5. 📋 Smart Attendance System
6. 🏆 Gamification & XP
7. 🧠 AI, Quizzes & Chatrooms
8. 🚀 Call to Action

**To record as video:**
- Open in Chrome
- Press **F11** for fullscreen
- Use **OBS Studio** or **Windows Game Bar** (Win+G) to record your screen
- Let it auto-play through all 8 slides (~40 seconds)
